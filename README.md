### Hi, I'm Victor

Software engineer, 12+ years building production systems (finance, aviation, public sector, ticketing).
On the side I do independent research on efficient inference: quantization, small decision models, and careful benchmarking.

**Research and projects**
- [diffusal](https://github.com/wfzyx/diffusal): do diffusion LMs tolerate low-bit quantization better than autoregressive ones? Matched pairs, thresholds set before each run. [Whitepaper](https://github.com/wfzyx/diffusal/tree/main/whitepaper)
- [newt](https://github.com/wfzyx/newt): retrofitting recurrent depth onto a 4B model, with a noise control that explained away the gains.
- [von](https://github.com/wfzyx/von): a small encoder model that picks between options or scores them in one pass, without generating text. Runs on CPU, Python and TypeScript SDKs.
- [rubick](https://github.com/wfzyx/rubick): chat, embeddings, and decisions served from one local model.
- [vole](https://github.com/wfzyx/vole): a Linux system cleaner, ported from Mole.
